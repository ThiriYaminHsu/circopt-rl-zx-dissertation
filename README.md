# circopt-rl-zx-dissertation

RL agents for ZX-calculus circuit optimisation (GATv2 actor-critic PPO), ablating
whether training on ripple-carry adders specifically ("Agent A") beats training on
random Clifford+T circuits ("Agent R", replicating Riu et al.'s regime) when both
are evaluated on held-out adders.

Built on the environment and reward design of Riu, Nogue, Vilaplana, Garcia-Saez &
Estarellas (2025), *"Reinforcement Learning Based Quantum Circuit Optimization via
ZX-Calculus"* (Quantum, 9), and its code at
[qilimanjaro-tech/Circopt-RL-ZXCalc](https://github.com/qilimanjaro-tech/Circopt-RL-ZXCalc).
This is an independent, reduced-scope reimplementation, not a port -- see
[`docs/deviations_from_paper.md`](docs/deviations_from_paper.md) for the full list of
differences.

## Structure

```
src/circopt_adder/   the package: env, model, PPO loop, generators, baselines, eval
scripts/             thin CLI entry points (train_agent_r.py, train_agent_a.py, evaluate.py)
benchmarks/           fetch_paper_circuits.py downloads Riu et al.'s benchmark circuits
notebooks/            exploratory Colab notebook (narrative companion, not source of truth)
results/              checkpoints/, logs/, figures/ -- all gitignored, regenerated by scripts/
tests/                 pytest sanity checks for the ZX rewrite rules
docs/                  deviations_from_paper.md
```

## Install

```bash
pip install -e .
```

## Usage

```bash
python scripts/train_agent_r.py --smoke-test   # random-circuit regime
python scripts/train_agent_a.py --smoke-test   # adder-specific regime
python scripts/evaluate.py                     # baselines + both agents, on random/adder/paper circuits
```

Drop `--smoke-test` once both training runs learn something on the reduced
timestep budget -- see `src/circopt_adder/config.py` for the full-scale settings
(`total_timesteps=2_000_000`, matching Riu et al.'s Table 1).
